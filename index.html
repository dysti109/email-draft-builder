Email Draft Builder

어떤 메일·요청이든 원문을 붙여넣고 필요한 파일을 선택해 EML 초안을 만드세요. 내용은 브라우저 안에서 처리되며 메일은 자동 발송되지 않습니다.

1. 원문과 파일

웹메일을 자동으로 읽지는 않습니다. 원문에서 복사한 텍스트를 붙여넣고, 첨부파일은 먼저 내려받아 아래에서 선택하세요.

선택된 파일 없음

2. 수신자와 추출 정보 확인

여러 주소는 쉼표로 구분하세요. 입력한 주소는 저장되지 않습니다.

3. 메일 템플릿

사용 가능한 변수: {{source_subject}}, {{source_text}}, {{name}}, {{email}}, {{date}}, {{deadline}}, {{url}}, {{quantity}}, {{details}}, {{response}}

4. 메일 미리보기

초안 파일을 메일 앱에서 열어 받는 사람, 본문, 첨부를 확인한 뒤 직접 발송하세요.
